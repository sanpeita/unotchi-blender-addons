## 1. ダウンロード

[Releases](../../releases) から、使いたいアドオンの `.zip` をダウンロードします。
（ファイルは解凍しないでください。Blender がそのまま読みます。）

## 2. Blender に入れる

1. Blender を起動する
2. `編集 > プリファレンス > Get Extensions` を開く
3. 右上のメニューから **Install from Disk**（ディスクからインストール）を選ぶ
4. ダウンロードした `.zip` を選ぶ
5. 一覧に出てくるので、チェックを入れて有効にする

ヒント: `.zip` を Blender のウィンドウにドラッグ&ドロップしても同じです。

## 3. 使う

各アドオンのパネルの場所:

| アドオン | 場所 |
|---|---|
| メッシュ診断・一括修復 | 3Dビューポート > N パネル > うのっち > Mesh Doctor |
| クネクネリグ自動生成 | 3Dビューポート > N パネル > Rigging > クネクネリグ |
| 雑リメッシュ（半減） | 3Dビューポート > N パネル > Remesh > 雑リメッシュ |

（N パネルは 3D ビューポートで `N` キーを押すと開きます）

## 4. こまったとき

- 一覧に出てこない → Blender のバージョン（4.2 以降が必要）と、zip を解凍していないか確認
- エラーが出た → `ウィンドウ > システムコンソール` を開いて、赤い文字をコピーして Issue へ
